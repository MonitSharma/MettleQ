Inspectable quantum simulation for Apple Silicon.

MettleQ provides exact statevector and bounded MPS simulation, native SDK adapters, memory preflight, explicit execution plans, and reproducible benchmark evidence.

Install

The accelerated simulator targets Apple Silicon Macs. MLX-independent drawing, QASM parsing, and documentation utilities can also be installed on other platforms.

Recommended SDK install

python -m pip install "mettleq[sdk]"

Requires Python 3.11+. The SDK extra includes Qiskit Aer and PennyLane Lightning for calibrated CPU fallbacks.

Source checkout

git clone https://github.com/MonitSharma/MettleQ.git
cd MettleQ
python -m pip install -e ".[dev,sdk]"

Use an editable install when developing kernels, adapters, tutorials, or tests.

Platform note: full MLX/Metal simulation requires macOS arm64. MettleQ does not combine CPU and GPU timings into a single claimed speedup.

Use it from your SDK

Qiskit

from qiskit import QuantumCircuit, transpile
from mettleq.integrations.qiskit import AdaptiveQiskitBackend

backend = AdaptiveQiskitBackend(precision="single")
circuit = QuantumCircuit(2)
circuit.h(0)
circuit.cx(0, 1)
result = backend.run(
    transpile(circuit, backend),
    shots=1000,
    seed_simulator=7,
).result()
print(result.get_counts())

PennyLane

import pennylane as qml

dev = qml.device("mettleq.adaptive", wires=2,
                 precision="single")

@qml.qnode(dev)
def bell():
    qml.Hadamard(0)
    qml.CNOT(wires=[0, 1])
    return qml.expval(qml.Z(0) @ qml.Z(1))

print(bell())

Test and release

The repository keeps correctness, packaging, and tutorial checks separate so a release can be audited before it is uploaded.

python -m pip install -e ".[dev,tests]"
pytest -q
python -m build
python -m twine check dist/*

For Apple Silicon validation, run ./test.sh, the SDK quickstarts, and the executable tutorial parity suite. See the public release checklist before making a repository public.
